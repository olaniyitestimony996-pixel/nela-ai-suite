## 📦 Download & Installation Wizard

To deploy the pre-compiled version of Nela AI on your laptop like a true consumer application, follow these simple steps:

### Step 1: Initialize the Background Neural Brain
1. Head over to the official site and download the setup file: [Ollama.com](https://ollama.com).
2. Install the application and verify that the little Ollama icon (the llama face) is awake and sitting right inside your bottom-right Windows taskbar clock tray workspace.
3. Pull down the mandatory intelligence model by opening your terminal (`cmd`) and running:
   ```bash
   ollama run qwen2.5:3b
   ```
   *(Once the 1.9GB download completes, you can close the command prompt safely!)*

### Step 2: Download & Launch Nela AI
1. Go to the **Releases** section on the right side of this GitHub repository page and download the compressed folder: `Nela_AI_V2.zip`.
2. Extract the ZIP folder completely to any directory on your hard drive.
3. Open the extracted directory folder and double-click the automated control launcher file:
   👉 **`Launch_Nela_AI.bat`**

> **Note to Users:** Always launch the app via the `.bat` file! It runs a deep health check on your background model parameters, starts up the `Nela ai.exe` main chat window panel, and closes the black terminal window trail automatically in less than a second!
